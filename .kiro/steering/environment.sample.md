# Local environment details (sample)

Copy this file to `environment.md` and fill in YOUR machine's specifics —
that file is personal, keep it out of commits. Cover, in a few lines:

- OS + the shell the agent runs under, with the quirks that bite (quoting,
  line continuation, drive switching, available Unix-style tools).
- Directory for custom temporary files.
- The preferred `--work-dir` for pyqenc runs.
- Where sample/source videos live, and which file is the default.
- Extra CLIs on PATH beyond the required ffmpeg / MKVToolNix.
