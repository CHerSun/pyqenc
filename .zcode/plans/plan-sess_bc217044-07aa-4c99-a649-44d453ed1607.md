# §83 rework — no measurement facts, no measurement sidecars

**The rule (dogma):** a run whose **attempts are unmeasured** (`plan.measures_attempts` False — fixed + `--no-measure` + no elimination applies: `--no-optimize` or single strategy; mode and strategy count are both part of the decision) writes **no attempt sidecars and no winner sidecars**. Winner artifacts become video-only (the hardlink stays). Everything else below is a *derived consequence*, each double-checked — not part of the rule.

**Attempt-aware completeness:** a pair is COMPLETE iff winner `.mkv` present **and** (winner `.yaml` present **or** attempts are unmeasured). Then:
- same-unmeasured rerun → COMPLETE, zero replay;
- upgraded rerun (attempts now measured) → `.yaml` missing → PARTIAL → `encode_chunk` exact-name pick-up finds the attempt file → `goto_eval` re-measures in place, never re-encodes;
- downgrade (attempts become unmeasured over measured artifacts) → COMPLETE (mkv present), old sidecars persist harmlessly;
- `_pair_rows` COMPLETE composition reads no sidecars (`frame_count=0` on recovery) — no payload changes.

## Consequences (derived, double-checks done)

1. **Winner scan skipped** — nothing to read; running empty would log the "frame-preservation check skipped" warning. The early per-strategy Σ check is consequently absent; merge's source-vs-merged `get_frame_count` check is the backstop (measurement-independent, verified live).
2. **`encoding.yaml` not written** — holds only `summary` + `frames` (:2559-2562), both empty when attempts are unmeasured; absence is display-only, never invalidation (Req 24, :2206-2207) and the fast-exit resurface is fully None-safe (:2314, :2333). A rerun with measured attempts rebuilds it via the processing path.
3. **Anchor fallback yields no anchor** — with no scan the election's `measured` list is empty → silent `None`; guard the call-site `winner_sizes` stat sweep (`scan is None → presentation_anchor = None`), which also kills the misleading "elected at the winner scan" line.
4. **Merge quality-knob plot skipped for ALL fixed runs** — gate on `plan.fixed_quality`: in fixed mode the knob is constant, so the per-chunk knob plot carries zero information regardless of measurement. Search runs keep it (search always measures attempts → winner sidecars exist → real data; merge.py:1392).
5. **`_presentation_targets` → `[]`** — already shipped in 0.30.x, stays.

**Unchanged from 0.30.x** (verified right): plan field + `measures_attempts` property, `resolve_encoding` kwarg, CLI flag, optimization skip branch, merge `_measure_quality` + log gating. Runs with measured attempts (search + flag, fixed + flag + optimize + multi, all defaults) otherwise byte-identical — the only measured-run behavior change is consequence 4 (fixed runs no longer render the flat knob plot).
