# §79 — FilterInstance discriminated union (flattened members, design B)

User-approved 2026-10-19 ("ok, agreed, let's implement") after the benefits review.

## Design

Each filter gains a config-side Instance model that **subclasses its Params model** + a defaulted `Literal` tag; `FilterInstance` becomes a discriminated-union alias over the 6 members, defined in `pyqenc/audio/filters.py` (house pattern: `MergedOutputSidecar`). The flat YAML form (`{type: peaknorm, target_dbfs: -1}`) becomes the **only** form — config, `model_dump()`, fingerprints all share it.

## Changes

**`pyqenc/audio/filters.py`** — new "Config-side instances" section: `PeakNormInstance(PeakNormParams)`, `LoudNormInstance`, `DynAudNormInstance`, `DownmixInstance`, `EncodeInstance`, `PassthroughInstance` (each just `type: Literal["<id>"] = "<id>"`), + `FilterInstance = Annotated[Union[...], Field(discriminator="type")]`. Add `frozen=True` to the 6 params models. `params_model` ClassVar: grep consumers — if only the dying `_resolve_and_validate`, delete it.

**`pyqenc/app_config.py`** — delete the `FilterInstance` class (248-312, incl. `_resolve_and_validate`) + `SerializeAsAny` import; import the union from filters; `_validate_chains` passthrough check → `isinstance(..., PassthroughInstance)`.

**`pyqenc/audio/chain.py`** — import `FilterInstance`/`EncodeInstance` from filters; `resolve_chain` narrows via isinstance; `_encode_params_from(inst: EncodeInstance)` direct fields — **cast deleted**; executor passes the instance itself as params.

**Tests** (5 files) — `_fi(type_id, **params)` helpers deleted, direct member construction (tag defaults); `TestExecutorHasNoFilterTypeBranch` keeps full strength via a test-local extended union (`TypeAdapter(Annotated[Union[<6 members>, _TwoPassInstance], discriminator])`); `test_app_config_properties` cast site → direct field; `test_audio_filters` fixtures drop `params_model` if the ClassVar dies. Invalid-config tests assert bare `ValidationError` — unaffected.

## Behavior changes (sanctioned, alpha/run-once)

Audio fingerprint tokens change shape → existing work dirs re-run audio once; legacy nested `{type, params: {...}}` dicts no longer parse (docs were always flat); config errors become pydantic tag errors (still `ValidationError` at load).
