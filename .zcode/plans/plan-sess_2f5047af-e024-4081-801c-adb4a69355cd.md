# Specs lifecycle overhaul — date prefixes, name revisions, `_archive/`

## Conventions being adopted

1. **Naming**: every spec folder becomes `YYYY-MM-DD <name>`.
2. **Date rule** (verified against in-file headers, git history, and filesystem timestamps): prefix = the in-file `- Created:` date when it is earlier than or equal to the folder's first git commit; otherwise the first git commit date, with the header corrected to match. The earliest spec is the foundational `quality-based-encoding-pipeline` (2026-03-15) — nothing predates it. The two 2025 headers were **wrong**, not import provenance: `standalone-measure` (claimed 2025-07-17) describes `job.yaml` and pipeline concepts introduced 2026-03-15/17, and even a year-typo reading (2026-07) is impossible (postdates its own git add 2026-04-02 and "updated 2026-04-03" note); filesystem mtimes are 2026-04-03. `vif-metric-support` (claimed 2025-07-22) is git-added 2026-04-10, same day as its Completed header. Both are corrected to git dates. Same correction applies to headers re-dated after folder creation: `quality-search-v3` (07-14 > git 05-02), `metrics-two-tier` (06-15 > git 04-22), `measure-phase-ux-overhaul` (05-01 > git 04-11), `pipeline-metrics-report` (Created 06-10 contradicts Completed 04-01; git 03-30).
3. **Name revision**: `metrics-two-tier` → **`app-metrics-two-tier`**, `pipeline-metrics-report` → **`app-metrics-report`**. App-metrics domain (wall-clock per phase, disk, recovery) is always `app-metrics-*`; measurement-metrics names stay as-is; steering rule: unqualified "metrics" = quality measurement (VIF/PSNR/SSIM/VMAF). The two domains are never chained as supersessions of each other.
4. **Status — two states, no tags**: `.kiro/specs/` root = active/current truth (default); `.kiro/specs/_archive/` = no longer actual (consumed by successor specs). Marking = `git mv`. Root shrinks 31 → 17.
5. **No "deprecated"**: bad specs are deleted outright — we either implement a spec or don't store it.
6. **No WIP tag**: in-progress stays visible via blank `Completed:` + task checkboxes.
