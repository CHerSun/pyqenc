# §20 — Optimization test-basis knobs → config; optimize mode → EncodingPlan

## Design rulings (from this session's discussion)

- New `optimization:` section; `optimize_tolerance` moves in renamed to **`tolerance`**; the four selection knobs live in a nested **`test_basis:`** group (first nested knob group; "test basis" matches optimization.py:752 log phrasing — new glossary term, registered in docs/glossary.md).
- **`optimize` leaves config entirely** — it's volatile run intent, like fixed-quality. `--no-optimize` stays the only flag (argparse `dest="optimize"`, `store_false`, default `True`), feeding `resolve_encoding(..., optimize=...)` which stamps **`EncodingPlan.optimize: bool`** (required, sibling of `fixed_quality`). Mode conditions become single-source (`plan.fixed_quality and plan.optimize`).
- Percent units everywhere (1.0 = 1%), consistent with tolerance.
- `_select_test_chunks` takes **one required object arg** — `_select_test_chunks(chunks, basis)` (§38 + §116 pass-objects direction); no function defaults; docstring cites default_config.yaml as the single source of truth.
- **Non-goals**: no new CLI flags for the basis knobs; basis params NOT invalidation keys in optimization.yaml (persisted `test_chunks` selection stays the recovery contract; work-dirs run-once); `random.sample` stays unseeded; selection algorithm unchanged; specs untouched.

## Target shape

```yaml
optimization:
  tolerance: 5.0   # strategies within this % of best size are all kept
  test_basis:
    chunk_percentage: 1.0         # % of chunks strategies are tested on
    min_chunks: 3                 # floor for small videos
    exclude_start_percent: 10.0   # opening/closing segments are
    exclude_end_percent: 10.0     #   unrepresentative — excluded
```

```python
class TestBasisConfig(BaseModel):
    model_config = ConfigDict(validate_assignment=True)
    chunk_percentage:      Annotated[float, Field(gt=0.0, le=100.0)]
    min_chunks:            Annotated[int,   Field(ge=1)]
    exclude_start_percent: Annotated[float, Field(ge=0.0, le=100.0)]
    exclude_end_percent:   Annotated[float, Field(ge=0.0, le=100.0)]
    # @model_validator(mode="after"): exclusions sum < 100, else ValueError

class OptimizationConfig(BaseModel):
    model_config = ConfigDict(validate_assignment=True)
    tolerance:   float
    test_basis:  TestBasisConfig
```
