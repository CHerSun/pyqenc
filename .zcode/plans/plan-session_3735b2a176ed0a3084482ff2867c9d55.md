# encoding.py: single-file restructure + processing-path cleanup — no core-logic changes

One file, `pyqenc/phases/encoding.py`, restructured internally (current order = legacy). Production call sites (`merge.py`, `optimization.py`) stay intact except the one-token `force=` removal in optimization's `_encode_pairs` call. Tests are NOT call sites — updated freely to the rework. Branch `refactor/encoding-processing-path` + PR, version bump 0.31.0.

**Stay public** — cross-module prod consumers or persisted-contract convention (matches optimization/merge sibling style where sidecar classes are public, bases private):
`EncodingPhase`, `EncodingPhaseResult` (merge/runner), `read_winner_sidecar` (merge, optimization), `ChunkEncoder` (optimization), `AttemptSidecar`, `WinnerSidecar`, `EncodingSidecar`, `LimterSummary`→`LimiterSummary`, `LimiterSummaryRow` (persisted formats).

**Stay private per your ruling** (optimization = same thing, treated as private; its deferred underscore imports unchanged): `_pair_rows`, `_orphan_strategy_rows`, `_encode_pairs`, `_recover_encoding_attempts`, `_PhaseRecovery`, `_EncodingRecovery`, and all existing underscore helpers.

## C. Processing-path cleanup (core logic unchanged)

1. **Single classification per run**: `_recover` stashes `_PhaseRecovery` on `self._pairs` (same precedent as `self._persisted`; nothing writes `encoded/` between the hooks within one `run()`). `_execute` consumes the stash; the old `encode_all_chunks` re-classification scan is deleted. The end-of-execute `_pair_rows` re-scan on failure stays (disk truth changed). Duplicated no-chunks/no-strategies guards in `_execute` deleted — `RecoveryError` owns them.
2. **`encode_all_chunks` shell deleted** — the phase owns encoder construction, log lines, duration-weighted `ProgressBar` (pre-advance from the stash), `asyncio.run(_encode_pairs(...))`, failed-chunks ERROR line; `_execute` becomes symmetric with OptimizationPhase's inline bar+run block. Dead seams removed with it: `encoding_yaml` param ("Unused"), `dry_run` branch (template owns previews), `force` (production always False; `--force` is wipe-permission at JobPhase).
3. **Param diet**: `phase_recovery` required on `_encode_pairs`; `force` deleted from `_encode_pairs`/`encode_chunk` (census: no live consumer). `_encode_chunk_async` kept.
4. **`encode_chunk` dedup**: one extracted "attempt concluded" step (targeted-metrics filter, worst-target, pass/fail + summary log with optional `[reused]` suffix, `search.record`, best-tracking) shared by the cache-hit and fresh branches — removes the ~90 duplicated lines and the `goto_eval` splice (existing attempt → valid sidecar ⇒ record(reused); stale ⇒ re-measure the existing file; absent ⇒ encode → measure → write sidecar; then the common record). Winner selection collapses to one site: `final_attempt or best_fail_attempt`, one `_finalize_winning_attempt` with `targets_met = search.best_targets_met`, one return path. The `frame_counts`/`all_metrics_by_path` session dicts become snapshots taken when the best changes.
5. **Orphan sweep dedup**: `_orphan_strategy_rows` (reporting) and curation (deleting) share `_orphaned_strategy_dirs`.
